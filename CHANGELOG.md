# Changelog

All notable changes to the enginehost-wolf-plugin wrapper on `plugin-core`.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - unreleased

### Added
- The wrapper: `WolfPlugin` in Enginehost's isolated runtime, the Android build for arm64-v8a
  and x86_64, Enginehost's file layer, the bundle metadata and line `0.1` on `creation`.
- First milestone: loads and logs a game's project data and shows a black frame; refuses Pro
  and protected games with a plain reason.
