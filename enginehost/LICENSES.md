# Enginehost WOLF RPG Editor bundle notices

The Wolf core is our own interpreter, written for Enginehost from behaviour descriptions
(`docs/behaviour/` on the engine branch), and it and this wrapper are distributed under GPL-3.0.
The complete licence text ships in this bundle as `LICENSE-GPL-3.0.txt`. Its complete
corresponding source is the `plugin/<line>` branch of the same repository as this bundle.

No WOLF RPG Editor runtime code, no game data and no archive key is included.

Images are decoded with stb_image by Sean Barrett (https://github.com/nothings/stb, commit
d14d46f6b44456eb88beac58cba833a4135d4c89), used under its MIT licence; it is also offered as
public domain. Its licence text ships as `LICENSE-stb.txt`. Ogg Vorbis sound is decoded with
stb_vorbis from the same commit.
